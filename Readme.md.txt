Sten sax påse

ett sten sax påse spel 
Funktionaltieter:
- Användaren kan välja mellan sten, sax och påse genom att klicka på en knapp.
- Datorn gör slumpmässiga val mellan sten, sax och påse.
- Användarens och datorns vav visas på webbsidan.
- Spelet avgör vem som vinner varje spelomgång.
- Resultatet visas tydligt på webbsidan.
- Vinnaren av varje spelomgång får en poäng.
- Vid oavgjort får ingen någon poäng.
- En poängtavla visar användarens och datorns totala poäng.
- Det visas tydligt framgå vem som leder spelet.
- Användaren kan flera gånger utan att ladda om webbsidan
