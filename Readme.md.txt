✊ Sten, sax, påse

Ett enkelt och interaktivt sten, sax, påse-spel där du spelar mot datorn. Spelet är byggt med HTML, CSS och JavaScript.

🎮 Om projektet

Projektet är en webbaserad version av det klassiska spelet sten, sax, påse. Du spelar mot datorn, som slumpmässigt väljer mellan sten, sax och påse varje omgång.

Spelet håller koll på poängen och visar vem som vinner varje omgång. Den som först når 10 poäng vinner spelet!

✨ Funktioner

Spela mot datorn – Välj mellan sten, sax och påse.

Slumpmässiga val – Datorn väljer slumpmässigt varje omgång.

Poängräkning – Håll koll på både spelarens och datorns poäng.

Oavgjorda omgångar – En räknare visar antalet oavgjorda omgångar.

Visuell återkoppling – Resultatet visas med olika färger beroende på om du vinner, förlorar eller spelar oavgjort.

Återställning – Börja om spelet och nollställ poängen.

Vinstvillkor – Den som först når 10 poäng vinner.

🛠️ Tekniker

Projektet är utvecklat med följande tekniker:

HTML5 – Webbplatsens struktur.

CSS3 – Design, layout och utseende.

JavaScript – Spelmekanik, slumpmässiga val och poängräkning.

🚀 Kom igång

1. Klona projektet

git clone https://github.com/Luddejh/Sten-sax-p-se.git

2. Gå till projektmappen

cd Sten-sax-p-se

3. Starta spelet

Öppna filen index.html i valfri webbläsare.

Ingen installation eller ytterligare programvara krävs.

🕹️ Spelregler

Välj sten, sax eller påse genom att klicka på motsvarande alternativ.

Datorn gör sitt slumpmässiga val.

Resultatet av omgången visas.

Poängen uppdateras automatiskt.

Reglerna är enkla:

Sten vinner över sax.

Sax vinner över påse.

Påse vinner över sten.

Samma val innebär oavgjort.

Den som först når 10 poäng vinner spelet.
